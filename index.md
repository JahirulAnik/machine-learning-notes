# Machine Learning Notes

Machine learning algorithms explained **step by step**. Every lesson answers three questions in the same order:

1. **Why do we need this algorithm?**
2. **What does it look like in real life?** One worked example runs through the whole note.
3. **How does it work, one step at a time?** Formulas, hand calculations, then code.

## Lessons

1. [[Linear Regression]]: fit a straight line, measure the error (MSE), and use derivatives and gradient descent to improve it.
2. [[Logistic Regression]]: turn a linear score into a probability with the sigmoid, and fit it by maximising the likelihood.

More algorithms will be added over time.

## Every note has the same layout

Why we need it, a real-life example, the explanation step by step, many features, evaluation, assumptions and limits, code, common mistakes, a cheat sheet, and exercises.
